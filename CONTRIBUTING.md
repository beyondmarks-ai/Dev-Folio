# Contributing

Thanks for helping improve DevFolio Gallery.

## Development workflow

1. Fork the repository and create a focused branch.
2. Run the site locally with python -m http.server 8000.
3. Make one logical change per pull request.
4. Verify desktop and mobile layouts.
5. Run the checks documented in README.md.
6. Describe the user-facing impact in the pull request.

## Portfolio entries

Add or update records directly in feed.json. Each entry requires a name and a valid public URL; a short professional tagline is optional.

Do not submit parked domains, unsafe links, duplicate websites, tracking-heavy URLs, or inaccessible private pages.

## Code standards

- Keep the project dependency-free unless a dependency is clearly justified.
- Preserve semantic HTML and keyboard accessibility.
- Respect the existing responsive layout and reduced-motion behavior.
- Avoid unrelated formatting or data changes.
- Never commit credentials, environment files, or generated browser artifacts.
